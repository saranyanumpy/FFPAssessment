# FFP_Assessment_Saranya

This project is a test automation framework for UI and API testing, developed as part of an assessment assignment. It leverages tools like Selenium, TestNG, Cucumber, Allure, and ExtentReports.

---

## 🛠 Tech Stack

- Java 8
- Maven
- Selenium WebDriver
- Rest Assured (API Testing)
- TestNG
- Cucumber (BDD)
- Allure Reports
- ExtentReports
- Log4j for logging
- WebDriverManager
- Apache POI for Excel interaction

---

## ✅ Features

- UI test automation for login and signup workflows
- API automation using Rest Assured with assertions
- CAPTCHA detection handling (skips validation when CAPTCHA is present)
- Logging using Log4j2
- Test reports generated using Allure and ExtentReports
- Browser compatibility: Chrome, Firefox, Edge

---
